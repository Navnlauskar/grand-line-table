# Grand Line Table

A One Piece tabletop adventure (D&D 5e + Dungeons & Devil Fruits) for you and your crew, in the browser.

**Play:** open the site, press **Host a new game**, and send your friends the invite link (or the room code).
The host's browser runs the game and keeps the save, so the host keeps the page open while everyone plays.

Private fan project, not affiliated with Eiichiro Oda, Shueisha, Toei Animation or Wizards of the Coast.
